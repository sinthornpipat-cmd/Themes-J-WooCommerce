Petchsiam Shop — WordPress + WooCommerce theme (v2.0)
=====================================================
ธีมร้านค้าของใช้พลาสติกในบ้าน (กล่องเก็บของ ตู้ลิ้นชัก ตะกร้าผ้า ถัง ชั้นวาง Heavy Duty ฯลฯ)

ติดตั้ง
1. ติดตั้งและเปิดใช้ปลั๊กอิน WooCommerce
2. Appearance → Themes → Add New → Upload Theme → petchsiam-shop.zip → Activate
3. Appearance → ข้อมูลตัวอย่าง (Demo) → "สร้างข้อมูลตัวอย่าง" (8 หมวดสินค้า, สินค้า, ไอเดียจัดบ้าน, รีวิว พร้อมรูป)
4. Appearance → Customize → "Petchsiam Shop": แบนเนอร์, เซกชันสินค้า (ใส่ slug หมวดหมู่), แถบประกาศ, ติดต่อ, สี
5. Appearance → Menus → กำหนดตำแหน่ง "เมนูหลัก" / "เมนูส่วนท้าย"
6. ก่อนเปิดเว็บจริง: กด "ลบข้อมูลตัวอย่างทั้งหมด" แล้วใส่สินค้า/รูปจริง

หน้าแรก: สไลด์แบนเนอร์ → แถบจุดขาย 4 ช่อง → ตารางหมวดหมู่ → เซกชันสินค้า 5 หมวด → ไอเดียจัดบ้าน → รีวิว → FAQ
Slug หมวดเริ่มต้น: storage-box, drawers-cabinet, laundry, kitchen, heavy-duty (แก้ได้ใน Customizer)

รูปตัวอย่าง (assets/img/) — วาดขึ้นใหม่เป็นภาพประกอบ ไม่ใช่รูปจริงของสินค้า
  hero-1..3 (1920x700), banner-2..5 (1920x500), product-1..8 (800x800), feed-1..6 (720x1120),
  avatar-1..4, popup.png, placeholder.jpg
  แบนเนอร์/ป๊อปอัปใช้รูปตัวอย่างเป็นค่าเริ่มต้น เปลี่ยนที่ Customizer (อัปโหลดใหม่ หรือ Remove เพื่อซ่อน)

WooCommerce
- รองรับ HPOS และ Cart/Checkout Blocks
- มินิคาร์ท (drawer): การ์ดสินค้า, ปุ่ม − / + และช่องกรอกจำนวน, ราคาต่อรายการและยอดรวมอัปเดตทันที
  (คำนวณฝั่งหน้าเว็บทันที แล้วยืนยันด้วยยอดจริงจากเซิร์ฟเวอร์ทุกครั้ง), ลบสินค้า, คูปอง, แถบส่งฟรี
- หน้า Cart: เปลี่ยนจำนวนแล้วอัปเดตยอดอัตโนมัติ (ไม่ต้องกด Update cart)
- ไซด์บาร์กรองสินค้า: Appearance → Widgets → "ตัวกรองสินค้า (Shop)"
- แถบสั่งซื้อติดล่างในหน้าสินค้า, ป้าย % ลดราคา, ปุ่ม +/- ทุกหน้า
- แถบส่งฟรี: ตั้งยอดที่ Customize → WooCommerce (0 = ซ่อน) และต้องตั้ง Free shipping ใน WooCommerce ให้ตรงกัน

ฟอนต์: Prompt + Noto Sans Thai (Google Fonts)

ส่วนท้าย (Footer) — แก้ไขได้ทุกจุด (v2.1)
-----------------------------------------
- Appearance → Customize → Petchsiam Shop → "ส่วนท้าย: ..." (6 หมวด: คอลัมน์ 1-4, ลิขสิทธิ์ & เครดิต, สี)
- ในหน้าตัวอย่างของ Customizer ให้เลื่อนลงไปที่ส่วนท้าย แล้วคลิกไอคอนดินสอข้างข้อความ จะกระโดดไปช่องแก้ไขของจุดนั้น
- แก้ได้: ชื่อบริษัท, ที่อยู่, โทร/แฟกซ์/อีเมล (รวมป้ายกำกับ), หัวข้อทุกคอลัมน์, ลิงก์ Shopee, ข้อความเชิญชวน+ฟอร์มอีเมล, โซเชียล 5 ช่อง,
  ข้อความลิขสิทธิ์ ({year} {site}), เครดิตมุมขวา (ปิดได้), สีพื้น/สีตัวอักษร, เปิด-ปิดแต่ละคอลัมน์
- รายการเมนูคอลัมน์ 2: Appearance → Menus (ตำแหน่ง "เมนูส่วนท้าย")
- เพิ่มเนื้อหาอื่นใต้แต่ละคอลัมน์: Appearance → Widgets → "ส่วนท้าย: คอลัมน์ 1-4"
- ช่องที่เว้นว่างจะถูกซ่อนอัตโนมัติ

v2.2 — แก้เลย์เอาต์หน้าสินค้า
- แก้บั๊ก: เนื้อหาชิดขอบจอ (padding ซ้าย-ขวาของ .wrap ถูก .content-wide ทับ) → ตอนนี้มีขอบซ้าย-ขวา และอยู่กึ่งกลางทุกหน้า (สินค้า, หมวดหมู่, ตะกร้า, ชำระเงิน, บัญชี)
- ขอบข้างปรับตามขนาดจอ (16–40px) ตัวแปร --gutter ใน style.css
- หน้าสินค้า: รูปอยู่ในกรอบการ์ด, ป้าย % อยู่มุมรูป, ปุ่ม Add to cart ใช้สี accent แทนสีม่วงเริ่มต้นของ WooCommerce

v2.3 — เลย์เอาต์หน้าร้านค้า/หน้าสินค้า
- เนื้อหาอยู่กึ่งกลาง มีขอบซ้าย-ขวาตามขนาดจอ (16–40px), ไม่มีเลื่อนซ้ายขวาบนมือถือ
- หน้าร้านค้า: กริด 4 → 3 → 2 คอลัมน์ (คอม/แท็บเล็ต/มือถือ), แถบ "จำนวนผลลัพธ์ + เรียงสินค้า" จัดเป็นแถวเดียว (มือถือเรียงซ้อน)
- ป้ายลดราคาในการ์ดสินค้าเป็นสี accent อยู่มุมซ้ายบนของรูป

v2.4.0 — โค้ดตามมาตรฐาน WordPress
- เพิ่มคำอธิบาย (docblock) ให้ทุกฟังก์ชันและทุก hook, หัวไฟล์ของทุกเทมเพลต
- แก้ DPS_VER ให้ดึงเวอร์ชันจาก style.css อัตโนมัติ (เดิมค้างที่ 1.0.0 ทำให้ CSS/JS เก่าค้างแคช)
- เอา short ternary (?:) ออก, sanitize/unslash ค่า $_POST ที่ใช้ตรวจ nonce

v2.4.1 — ตรวจ WPCS รอบสอง
- แก้ค่าเริ่มต้นเก่าจากธีมแรกที่ตกค้าง: แถบประกาศ "ครบ 1,000 รับส่วนลด 1,000" และป้าย "ซื้อ 1,000 แถม 1,000" ในการ์ดสินค้าหน้าแรก
- ใส่วงเล็บปีกกาให้ if/foreach บรรทัดเดียวทั้งหมด, แยกการกำหนดค่าออกจากเงื่อนไข, escape ผลลัพธ์ในการ์ดสินค้า

v2.5.0 — แก้ระยะขอบหน้าสินค้า + ตะกร้าเด้งขวา
- สาเหตุ: หน้าสินค้าเดี่ยวไม่เรียก hook woocommerce_before_main_content จึงไม่มีกรอบ <main class="wrap"> → ย้ายกรอบไปไว้ใน woocommerce.php โดยตรง (ใช้ได้ทั้งร้านค้า หมวดหมู่ และสินค้าเดี่ยว)
- กด Add to cart ในหน้าสินค้า → เพิ่มแบบ AJAX แล้วลิ้นชัก "ตะกร้าสินค้า" เลื่อนออกมาทางขวา (สินค้าตัวเลือกที่ยังไม่เลือกจะแจ้งเตือนตามปกติ)

v2.5.1 — แก้ลิ้นชักตะกร้า
- รายการสินค้าในลิ้นชักเรียงผิด เพราะ CSS ของ WooCommerce (cart_list/product_list_widget) → เอาคลาสออกและกันสไตล์ซ้อนแล้ว
- ปุ่ม Add to cart ในหน้าร้านค้า/หน้าแรก ใช้ระบบเพิ่มสินค้าของธีมเอง (ไม่พึ่งสคริปต์ของ WooCommerce) แล้วเปิดลิ้นชักด้านขวาทุกครั้ง
- ยกลิ้นชักให้อยู่เหนือปุ่มแชทลอย และเว้นที่ไม่ให้ปุ่มชำระเงินถูกบัง

v2.5.2 — ลิ้นชักตะกร้าเร็วขึ้น
- กด Add to cart แล้วลิ้นชักเปิดทันที (แสดงสถานะกำลังโหลด) ไม่ต้องรอเซิร์ฟเวอร์ตอบก่อน
- รวมการเพิ่มสินค้า + ขอข้อมูลตะกร้าเป็นคำขอเดียว ผ่านปลายทาง ?wc-ajax=dps_add_to_cart ซึ่งเบากว่า admin-ajax
- หน้าสินค้าเดี่ยวไม่ต้องโหลดทั้งหน้ากลับมาอีกต่อไป

v2.5.3 — หน้า Cart
- ซ่อนปุ่ม Update cart เมื่อ JavaScript ทำงาน (เปลี่ยนจำนวนแล้วยอดอัปเดตอัตโนมัติ); ผู้ใช้ที่ปิด JS ยังเห็นปุ่มตามเดิม

v2.6.0 — หน้า Checkout สไตล์ 2 คอลัมน์
- ซ้าย: ฟอร์มอีเมล/ที่อยู่จัดส่ง ช่องกรอกขอบมน; ขวา: สรุปคำสั่งซื้อพื้นหลังเทาเต็มขอบจอ (มือถือ: สรุปขึ้นก่อนแล้วฟอร์มตามหลัง)
- สรุปคำสั่งซื้อมีรูปสินค้าพร้อมป้ายจำนวน, ช่องรหัสส่วนลดพร้อมปุ่ม "นำไปใช้" (ไม่ต้องกดลิงก์ "มีคูปอง?" ด้านบนอีก), ยอดรวมย่อย/ค่าส่ง/ภาษี/ยอดรวม
- รองรับทั้ง Checkout แบบคลาสสิก (เทมเพลต woocommerce/checkout/review-order.php) และ Checkout Block (ปรับด้วย CSS)
- ไฟล์ใหม่: inc/checkout.php

v2.6.1 — แก้ข้อความหน้า Checkout ได้
- Customizer > Petchsiam > "ข้อความหน้า Checkout": แก้ชื่อช่อง (ชื่อ, นามสกุล, ที่อยู่, จังหวัด, รหัสไปรษณีย์, เบอร์โทร ฯลฯ), หมายเหตุคำสั่งซื้อ และหัวข้อ 3 จุด เว้นว่าง = ค่าเดิม
- ใช้กับ Checkout แบบคลาสสิก (Checkout Block แก้ในตัวแก้ไขบล็อกของหน้า Checkout)

v2.7.0 — Checkout + ความเร็ว
- Checkout: เพิ่มระยะซ้ายขวา (ตัวแปร --co-pad), คอลัมน์ซ้าย/ขวาแบ่ง 50/50 ให้แถบเทาตรงกับสรุปคำสั่งซื้อ; บนมือถือแสดง Billing details ก่อนเสมอ แล้วตามด้วยสรุปคำสั่งซื้อ
- ฟอนต์ Google โหลดแบบไม่บล็อกการแสดงผล + preconnect
- สคริปต์ของธีม defer (WP 6.3+), preload แบนเนอร์แรกของหน้าแรก
- ปิด cart-fragments ของ WooCommerce นอกหน้า Cart/Checkout (ลดคำขอเซิร์ฟเวอร์ 1 ครั้ง/หน้า) — ปิดโหมดนี้ได้ใน Customizer > WooCommerce
- เปลี่ยนจำนวน/คูปองในลิ้นชักตะกร้าใช้ ?wc-ajax= (เบากว่า admin-ajax.php)
- ตัด emoji/embed/meta ที่ไม่ใช้ออกจาก head; WP_Query หน้าแรกไม่นับหน้า (no_found_rows)
- ไฟล์ใหม่: inc/performance.php
