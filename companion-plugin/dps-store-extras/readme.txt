ฟีเจอร์ของร้านที่ WordPress.org ไม่อนุญาตให้อยู่ในธีม ย้ายมาจากธีม Themes J WooCommerce เพื่อใช้คู่กับธีม J Shop

== ฟีเจอร์ ==

* รีวิวลูกค้า, คำถามที่พบบ่อย (FAQ), ไอเดียจัดบ้าน (Custom Post Types + meta box) ธีม J Shop แสดงบนหน้าแรกให้อัตโนมัติ
* Appearance → ข้อมูลตัวอย่าง (Demo): สร้าง/ลบสินค้า รีวิว ไอเดียจัดบ้านตัวอย่างพร้อมรูป
* Customizer → WooCommerce → ข้อความหน้า Checkout: แก้ชื่อช่องกรอกและหัวข้อในหน้าชำระเงิน
* Customizer → WooCommerce → ความเร็ว: ไม่โหลด cart fragments ทุกหน้า, ตัด emoji/meta ที่ไม่ใช้ออกจาก head, บังคับ AJAX add to cart
* ย้ายค่า Customizer จากธีมเดิม (Themes J WooCommerce / Petchsiam Shop) มาที่ J Shop ให้อัตโนมัติครั้งเดียว เมื่อเปิดหน้า admin ครั้งแรกหลังเปิดใช้ J Shop

== ติดตั้ง ==

Plugins → Add New → Upload Plugin → เลือก dps-store-extras.zip → Activate
ข้อมูลรีวิว/FAQ/ไอเดียจัดบ้านที่มีอยู่แล้วในเว็บจะกลับมาแสดงทันที (ใช้ post type ชื่อเดิม)
